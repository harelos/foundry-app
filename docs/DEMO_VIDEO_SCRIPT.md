## Core idea

Foundry builds Foundry. The proof is not a wall of agents. It is a visible brief, two accountable workers, one shared folder, a review gate, and a finished launch artifact.

## Capture rules

- Record the real installed Windows build, not a browser tab or localhost address.
- Use a clean demo workspace with synthetic client information.
- Keep provider account names and local paths out of frame.
- Show one real deliverable being created and accepted. Do not imply that Foundry published an ad or changed a live store.
- Use 1440x900 for the master capture; crop a separate 9:16 cut instead of auto-reframing the desktop recording.
- Keep each cursor action deliberate. No sped-up typing that makes the workflow look staged.

## Voice direction

American English, grounded operator voice, medium pace, no cinematic growl, no exaggerated startup enthusiasm. Read in complete sentences. The proof moment is: "We used Foundry to build Foundry."
